# Evokai Portfolio

Personal portfolio of Fernando Cuen Pérez (Evokai). A static site: `index.html` plus the `media/` folder.

- Hosted on Cloudflare Pages: every push to `main` deploys automatically.
- No build step. In Cloudflare Pages leave "Build command" empty and set "Build output directory" to `/`.
- Project videos are YouTube embeds and play inline on the live domain.
